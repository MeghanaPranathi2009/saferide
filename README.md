# SafeRide — Smart Student Journey & Safety Monitoring (MDP demo)

React + Vite. **Demo only**: fictional data, simulated events, stored in the browser (localStorage).

**Not implemented:** real GPS, notifications, wristband integration, login, Firebase (a plan is in `src/db.js`).

## Run locally
    npm install
    npm run dev
    npm run build

## Publish
Push to GitHub, then import the repo in Vercel (Framework: Vite, defaults are fine).
Never commit `.env.local` or real student data.
